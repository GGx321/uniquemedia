# uniquemedia — Instagram Video Uniquifier (engine + CLI)

Turns one source video into N verified-unique copies using randomized 2D and
pseudo-3D FFmpeg transforms, then verifies each copy with a PDQ-style perceptual
hash so it provably crosses a Hamming-distance threshold.

## Requirements
- bun

## Install
    bun install

## Usage
    bun run src/cli.ts <input.mp4> --count 30 --format reels --out out

Flags:
- `--count N` number of copies
- `--strength` visual-change multiplier (~0.5..1.5, default 1.0)
- `--format original|reels|feed|square`
- `--out DIR` output directory (default: out)
- `--target` minimum PDQ Hamming distance each copy must exceed (0..256, default 60)
- `--keep-audio` keep trend audio (no audio modification)
- `--mirror` allow horizontal flip
- `--no-spoof` disable iPhone metadata spoofing (strip all metadata instead)
- `--seed` base seed for reproducible batches

## Test
    bun test

## Desktop app (Electron UI)

    bun install
    bun run dev      # launches the Electron app

Drop a video, set the number of copies, choose a format, press Uniquify, and watch
the queue fill with verified-unique copies (live progress + uniqueness badges).
Strength is auto-managed (the verification loop guarantees the threshold); a manual
strength slider lives under "Дополнительно". Build a distributable with `bun run build`.

## 🎬 Что приложение делает с видео (полное описание)

Из одного видео создаётся N копий. Каждой копии назначается случайный набор
параметров (свой seed), за **один проход** перекодирования применяется набор
трансформаций, затем считается перцептивный хэш **PDQ** и копия **гарантированно**
доводится до порога уникальности (если не дотянула — эффекты авто-усиливаются и
копия перегенерируется). Дополнительно копии сравниваются между собой, чтобы не
было двух похожих.

Все значения ниже даны для **силы изменений 100%** (по умолчанию). Параметры
случайны в указанных пределах на каждую копию и масштабируются ползунком «Сила
изменений».

### 1. Цвет и тон (применяется всегда)
- **Яркость** — сдвиг ±0.05
- **Контраст** — ×(1 ± 0.06)
- **Насыщенность** — ×(1 ± 0.08)
- **Гамма** — ×(1 ± 0.06)
- **Оттенок (hue)** — поворот цветового тона ±6°

### 2. Геометрия (незаметная глазу)
- **Зум + кроп** — увеличение до +8% с обрезкой обратно к кадру (сильно меняет
  отпечаток, глазу почти не видно)
- **Поворот** — ±0.05° (физически незаметно)
- **Перспектива (наклон плоскости)** — ~0.002 (незаметно)
- **Линза (barrel/pincushion)** — k1 ±0.015 (едва заметная дисторсия краёв)
- **Зеркало по горизонтали** — только если включить в «Дополнительно» (по умолчанию
  ВЫКЛ, чтобы не отражать текст)

### 3. Детали
- **Шум/зерно** — сила 0–14 (живая зернистость, не видна в движении)
- **Виньетка** — лёгкое затемнение краёв, включается примерно в 60% копий

### 4. Скорость и длительность
- **Скорость** — 0.95–1.05× (±5%); меняется и видео, и звук синхронно
- **Длительность** — соответственно меняется на эти же ±5%

### 5. Звук
- **Темп (atempo)** — синхронизируется со скоростью видео, высота тона (питч)
  **сохраняется**
- **Микро-эквалайзер** — лёгкая коррекция на 3000 Гц, ±2.5 дБ (ломает
  аудио-фингерпринт)
- **Перекодирование** — AAC, битрейт случайный 96/112/128/160 кбит/с
- **«Сохранить оригинальный звук»** — отключает эквалайзер (оставляет только
  синхронизацию темпа), если важно попасть в тренд-аудио
- Если в исходнике нет звука — дорожка не добавляется

### 6. Метаданные — подделка под iPhone (по умолчанию ВКЛ)
По умолчанию каждой копии проставляются правдоподобные метаданные «снято на iPhone»
(тумблер «Метаданные iPhone» в «Дополнительно»):
- **Модель** — случайный iPhone от 11 до 17 Pro Max
- **iOS** — случайная версия 26.x
- **Дата/время съёмки** — случайная в недавнем прошлом, с таймзоной США
- **Геолокация (GPS)** — случайный реальный город США (Лос-Анджелес, Нью-Йорк,
  Чикаго, Майами…), таймзона согласована с координатами
- **Контейнер как у iPhone** — QuickTime-brand (`qt`), хэндлеры «Core Media
  Video/Audio», H.264 High / bt709 — совпадает с тем, как снимает реальный айфон
- Каждая копия — свой случайный «телефон», поэтому копии выглядят снятыми на разные
  устройства

Если тумблер выключить — вместо подделки метаданные **полностью стираются**
(`-map_metadata -1`): чистый файл без следов оригинала и устройства.

### 7. Кодек, размер, формат файла
- **Видеокодек** — H.264 (libx264), preset случайный (`faster`/`veryfast`),
  **CRF случайный 18–26** → у каждой копии разный битрейт/качество/битовый профиль
- **Частота кадров** — принудительный CFR, fps случайный 24/25/30, GOP 2–4 сек
  (`-fps_mode cfr -r -g -keyint_min`) — ломает GOP-структуру исходника
- **Аудио-битрейт** — случайный 96/112/128/160 кбит/с (не константа)
- **Пиксельный формат** — yuv420p
- **Контейнер** — MP4, флаг `+faststart`
- **Разрешение** — формат на выбор: **Оригинал** (сохраняет исходное соотношение и
  разрешение, без подгонки), Reels 9:16 → 1080×1920, Лента 4:5 → 1080×1350,
  Квадрат 1:1 → 1080×1080 (для фиксированных — масштаб «с покрытием» + обрезка по
  центру, SAR=1)
- **Размер файла** — практически всегда отличается от оригинала
- **Бинарный хэш файла (MD5/SHA)** — уникальный у каждой копии

### Что в итоге сдвигается
| Слой | Результат |
|---|---|
| Перцептивный хэш (PDQ, как у Meta) | гарантированно за порогом — измеримо проверяется |
| Аудио-фингерпринт | сдвинут (темп + EQ), кроме режима «сохранить тренд-аудио» |
| Метаданные | заменены на правдоподобные iPhone (модель/iOS/дата/GPS) или полностью стёрты — на выбор |
| Бинарный хэш файла | всегда уникальный |
| Разрешение / размер / длительность | изменены |
| Копии между собой | гарантированно различны (дедуп) |

### Чего приложение НЕ делает
- Не добавляет водяные знаки, логотипы, рамки, интро/аутро
- Не меняет смысл контента (текст, объекты, сцена остаются как есть)
- Не делает настоящий depth-3D parallax (запланировано отдельно; текущее «3D» —
  это лёгкая perspective/линза)
- Ничего никуда не загружает — вся обработка локально, видео не покидает компьютер

## Notes
This transforms your own content; mass-posting may violate Instagram ToS — risk
is on the user. "Uniqueness" is measured, not guaranteed against a black box.
