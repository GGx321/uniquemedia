# Studio — Stage 3 plan: Reels montage

File: `docs/studio/2026-09-29-stage-3-plan.md`.

Status: final for dispatch. It folds in:
- the owner's answers of 2026-09-29, including the V1–V4 defaults, all accepted;
- the critic review (the plan critique's findings A1–A5, S1–S20, the nits and cuts);
- the critic's v2 verification: B1, B2, C and its backlog items 1–11, all applied.

No owner question is open. The layer and clip caps are a decision that can be raised later
(see the Timeline row). The controller is confirming them with the owner.

Goal: turn an avatar's generated scene photos, and the owner's own uploads, into a finished
Instagram Reel (a 9:16 MP4) in a timeline editor. It should feel "roughly like Canva's video
editor, not as complex as CapCut". The same result must be reachable with no UI at all: every
montage is a data record (`MontageSpec`), and the engine renders it headless. Stage 4's
autopilot will generate those records and render them in bulk.

  crossfade can be added later.

## Slices

Each slice can be released on its own. What a slice has not built stays unreachable. Until
its slice lands, the engine refuses any spec part that needs it, with `MONTAGE_INVALID` "not
yet supported"; it never drops that part silently (N9). The UI controls for it stay disabled,
titled «Скоро».

- **3a — the render core, headless.**
  - The `MontageSpec` timeline contract.
  - The eligibility rule, the derived "used" index and the reject marks.
  - Shared geometry and timing, and focus resolution.
  - The two-pass graph builder, the render queue and runner, the output verifier, video
    records.
  - A packaged headless E2E.
  - Photo and collage clips only.
- **3b — the media protocol, text and stickers.**
  - All `studio-media://` routes with Range support.
  - Fonts plus an emoji font, the caption rules, and text layout and rasterising owned by the
    engine.
  - A generated sticker set, and layers in the graph.
- **3c — music.**
  - The RapidAPI key and the flashapi client with a quota ledger, manual refresh only.
  - The track store, and the peak-safe audio chain.
  - The Settings «Музыка» card.
- **3d — the Montage screen (the timeline editor)**, built from the the Stage 3 artboards in the Claude Design canvas
  artboards.
  - Drafts, the timeline, the preview, the properties and media panels.
  - Rendering and the render queue.
- **3e — videos and photo usage.**
  - The Photos «Видео» tab.
  - The «Неиспользованные» and «Отклонённые» filters, reject and restore.
  - The counts, and the export folder.
- **3f — own uploads («Мои»).**
  - Own photos, own videos (MP4/MOV; trim, rotation, HDR/VFR normalisation), own music and own
    stickers.
  - All of them come through main's file dialog.

Order:
- **First, in parallel:** SP1–SP3 and SP5 (SP0 is done), 3a, and the designer's artboards
  (already in progress).
- **Then:** 3b and 3c.2–3c.4 alongside 3a's second half. After 3a.5: 3b.6 and 3c.5.
- **3d** after 3a, 3b and 3c.4, plus the owner's review of the artboards.
- **3e** after 3a.8 and 3b.1.
- **3f** last.

Prerequisites from the queued Stage 2 debts land first, or 3a.1 absorbs them:
- Job events carry `kind` and `avatarId` (plus `runId` or `videoId`).
- 2K is removed end to end (the owner dropped 2K; 1K only).

Task sizing: each task is one review surface. A reviewer can verify it in one pass, which
leaves room within the limit of 3 review→fix rounds.

## Money and quota model

**Money:** unchanged from Stage 2, and not touched by Stage 3.

**The flashapi quota ledger** (`userData/music-quota.jsonl`) is append-only and fsynced after
each append.

Lines:
- `send { requestId, at }` is written **before** the request leaves.
- `result { requestId, status, remaining, limit, headerNames, at }` follows it.

Rules:
- Every `send` counts, whether its request succeeded or not. So does a `send` with no
  `result` after a crash.
- A torn last line counts as a `send`. The rule is conservative; the next append repairs the
  file.
- Only a user click sends a request. There is one refresh at a time and never a retry.

## Montage as data — `MontageSpec` v1 (the sketch for 3a.1)

```
MontageSpec {
  schemaVersion: 1
  avatarId: Id
  clips:  Clip[]     // 1..20, played back to back; Σ durationMs ∈ 4000..15000
  layers: Layer[]    // 0..20 (≤ 10 text, ≤ 10 sticker); array order = z-order, later on top
  music:  null
        | { source: "trending", trackId: Id, startMs: int ≥ 0 }
        | { source: "own", mediaId: Id, startMs: int ≥ 0 }            // 3f
  seed:   uint32     // pan direction, Ken Burns in/out: variety for the autopilot
}

Clip = { clipId: Id, durationMs: 500..15000 (multiple of 100), transitionIn: "cut" } & one of:
  { kind: "photo",   cell: Cell, motion: Motion }
  { kind: "collage", layout: "collage2" | "collage3" | "collage4",
                     cells: Cell[] (exactly 2 / 3 / 4), motion: Motion, stagger: boolean }
  { kind: "video",   mediaId: Id, trimStartMs: int ≥ 0, focus: Focus | null }   // own upload, 3f; static

Cell   = { photo: { source: "scene", photoId: Id } | { source: "own", mediaId: Id },   // own: 3f
           focus: Focus | null }          // null only from headless callers; drafts always store it
Focus  = { x: 0..1, y: 0..1 }
Motion = "kenburns" | "pan" | "static"

Layer = { layerId: Id, startMs, endMs }   // multiples of 100; 0 ≤ start < end ≤ total; end − start ≥ 300
  & one of:
  { kind: "text",    value: Caption, font: "manrope" | "playfair" | "oswald" | "ptmono" | "caveat",
                     style: "none" | "plaque" | "outline", x: 0..1, y: 0..1 (box centre), scale: 0.5..2 }
  { kind: "sticker", sticker: { source: "builtin", stickerId: Id } | { source: "own", mediaId: Id },
                     x: 0..1, y: 0..1 (centre), size: 0.05..0.6 (of frame width) }
```

Rules beyond the shape:
- A scene photo appears at most once per montage.
- `transitionIn` has one value today, `"cut"`. Stage 3 uses hard cuts only (V1). A crossfade
  can be added later without breaking the schema.
- The engine adds a **resolved** part, stored only in the video sidecar:
  - the focus values filled in;
  - each text layer's `{ lines, sizePx, box }`;
  - each clip's frame range;
  - the music's `{ startMs, gainDb, trackSha }`;
  - the sha256 of every input file.

`defaultSpec(avatarId, photoIds)`, shared by «Монтаж из выбранных · N» and the autopilot:

| Photos selected | Default montage |
| --- | --- |
| 1 | one photo clip, 8.0 s, Ken Burns |
| 2–4 | one collage clip of that size, 8.0 s, Ken Burns, stagger on |
| 5 ≤ N ≤ 20 | N photo clips of `clamp(N × 1.3 s, 4, 15)` total, split evenly (the old «Слайды»); 20 photos give 0.75 s each |
| N > 20 | refused: `photoIds` is capped at 20 in the contract, the same as the clip cap. The UI disables «Монтаж из выбранных» above 20 and says why (backlog 7). |

Validation has two halves:
- **Structural** (Zod, shared): shape, bounds and the caption rules.
- **Referential** (engine):
  - scene photos are eligible (the rule above);
  - own media exists and has the right kind;
  - the track is cached and at least `startMs + total` long;
  - stickers exist;
  - fonts cover the text (statically guaranteed, N17).

Stage 4 mapping: the Autopilot artboard's «Одно фото / Коллаж 2–4 / Слайды» mix maps onto
`defaultSpec`'s three shapes. Its «фото на видео» numbers are 1 / 3 / 5.

## Invariants (tests must pin each; numbering continues Stage 2's 1–13)

14. **Metadata allowlist** — as the Metadata row states, checked before commit. Tests render
    from EXIF-, XMP- and C2PA-laden photo fixtures and from an audio file carrying
    title/artist tags. They assert the allowlist exactly, with ffprobe and with the box walker.
15. **No network in render.**
    - Every ffmpeg input is a local path under the library, `userData/music`,
      `userData/render-tmp/<jobId>` or the app assets, and carries
      `-protocol_whitelist file`. The concat list
      holds only the job's fixed relative names.
    - A static test finds no fetch or network import in the render modules.
16. **No text or path in `-filter_complex`.** The graph string uses a strict charset: numbers,
    filter names, labels, fixed option names. A property test covers random valid specs.
17. **SVG text is inert** (A3).
    - Text enters the fixed SVG template only as XML-escaped character data. resvg gets no
      resources dir and no external `href`.
    - A property test with `<`, `>`, `&`, `]]>`, quotes and `<path d=…/>` shows each rendered
      literally, with no extra shapes.
18. **Only eligible scene photos.** Each of the following is refused with
    `PHOTO_UNAVAILABLE` before ffmpeg starts: a candidate, the master, an imported avatar's
    photo, an age-failed candidate, a rejected photo, another avatar's photo, a missing
    photo. The same single function answers `photos.list`, the bin, the counts and
    `eligibleUnusedPhotos` (A1).
19. **Caption rules.** Charset (with emoji coverage), length, lines, youth words and emoji,
    and the number table, at both the contract and the engine. Cyrillic, an uncovered emoji,
    a youth emoji and "teen" are each refused with their Russian message.
20. **Exact A/V length** (S6).
    - **Video:** exactly `Σ durationMs × 3 / 100` frames.
    - **Audio:** built in-graph with `apad,atrim=end_sample=Σ durationMs × 48`. Its duration is
      ≤ the video's and ≥ the video's minus one AAC frame (21.3 ms).
    - **Never** use `-frames:v`, `-t` or `-shortest` as the terminator.
    - With no music, the track is silent.
21. **Audio peak safety** (A5): the output's true peak is ≤ −1 dBTP, and the applied gain is
    never above 0 dB. Tests cover three fixtures (backlog 9): a hot track (TP +0.4), a
    threshold track (TP −1.6, which sits right at the −1.5 target), and a quiet one (TP −5.2).
    The critic's probe measured the AAC-LC 192k re-encode overshoot at ≤ 0.1 dB.
22. **Fonts.** Text renders only with the bundled font files, their sha256 pinned. A static
    test proves that each TTF's cmap, and the emoji font's coverage, include the whole
    allowed charset (N17). No system fonts, no fontconfig.
23. **Video write order** (the Commit row).
    - `videos/` never holds a partial file, and the sidecar is write-once.
    - On start, an MP4 without a sidecar goes to `quarantine/`, and both `<library>/staging/*`
      and `userData/render-tmp/*` are swept.
    - The sweep **tolerates EBUSY and EPERM** (a file still held by an orphaned ffmpeg): it
      skips the file, retries on the next start, and never fails the library open (S5).
24. **"Used" is derived** from committed sidecars (A2), and a delete frees the photos.
    Photos named by queued or running render specs are never returned by
    `eligibleUnusedPhotos` (S16). The library takes an injected reserved-set provider in
    3a.2. The two-queued-specs test runs in 3a.6, where the queue exists (backlog 4). Own
    media never appear in used or unused counts.
25. **Bounded renders and a real queue** (S10).
    - Queued jobs appear in `Snapshot.jobs`, can be cancelled, and count toward `IN_FLIGHT`.
      A library switch is refused while any render is queued or running.
    - Every render has a timeout. A cancel or timeout kills ffmpeg and leaves no visible file.
26. **Stage 3 spends nothing.** The modules under `studio/engine/montage/**`, `render/**`,
    `music/**` and `media/**` never import `openrouter` or `money`: a static test.
27. **Headless.** `videos.render {spec}` works with no window. The packaged E2E drives it over
    the control channel.
28. **The media protocol, widened** (S2).
    - **Routes:** `video/<avatarId>/<videoId>`, `track/<trackId>`, `cover/<trackId>`,
      `sticker/<stickerId>`, `text/<previewId>`, `media/<mediaId>`. The `photo` route stays.
    - **Checks on every route:** id-only, naming convention, `realpath` inside its own root, a
      MIME allowlist, HTTP Range.
    - **Scheme and CSP:** the scheme is registered with `stream: true`; the CSP adds
      `media-src studio-media:`.
29. **The music key and child envs.** The RapidAPI key lives only in its `KeyStore`
    (`safeStorage`, main) and the engine's memory: never in the renderer, logs, library,
    cache files or quota lines. The flashapi client takes the key and the base URL as
    parameters, and tests never pass a real key. Every ffmpeg child's env keys are a subset
    of the engine env allowlist (S4).
30. **Quota.**
    - A `send` line is on disk before the request leaves.
    - The 31-day window, the `remaining = 0` floor, no retry and no overlap all hold.
    - Tests: a crash between `send` and `result`, a torn last line, and the boundary: with 29
      sends in the window a request leaves; with 30 it is refused.
31. **Downloads.**
    - **Sources:** `https` only, from the allowlisted hosts (`*.cdninstagram.com`,
      `*.fbcdn.net`; the spike cache confirms both, N7), with no redirect off the list.
    - **Size caps:** 25 MB per track, 2 MB per cover.
    - **Acceptance:** a track is accepted only after a bounded decode proves it is audio, and
      its sha256 is recorded.
    - **Test overrides:** the E2E-only mock-CDN host override and the base-URL override are
      both compiled out of packaged production builds (invariant 13 extended, S11).
32. **Unsupported until landed** (N9). A spec using layers, music or own media before its
    slice ships is refused with `MONTAGE_INVALID` "not yet supported", never dropped.
33. **Unique export names** under parallel renders: an exclusive create plus the next NNN. Two
    concurrent commits never share a name (S15).
34. **Own uploads come in through main only.** The renderer never sends a path or bytes: the
    T6c rule. The path comes only from main's own native dialog, over the control channel.
    Unlike T6c, which passed bytes, the engine now opens a user-picked path, because 2 GB
    videos cannot travel as bytes. So the handoff is spelled out (backlog 10):
    - an `lstat` check that it is a **regular file**;
    - **no symlink following**: a symlink, a directory or a device is refused, and the file
      is opened with `O_NOFOLLOW` where the platform has it;
    - a **byte-capped** copy into staging that stops at the kind's cap even if the file
      grows during the copy;
    - validation and normalisation before anything else reads it.

    The imported file keeps none of its source metadata.

## Risks

| Risk | Impact | Mitigation |
| --- | --- | --- |
| Memory with long timelines or collages | Out-of-memory, or a slow machine | Two-pass rendering bounds memory per clip. SP1 records peak RSS per clip kind. «Авто» includes the RAM term (S7). |
| An orphaned ffmpeg after an engine crash | EBUSY in the sweep on Windows; a stray file | The sweep tolerates it and retries on the next start. The Windows kill test kills only the engine (S5). |
| `resvg-wasm` or the emoji font inside the asar | No text, or no emoji | SP2 first. The packaged smoke in 3b. |
| ffmpeg differs by platform (6.0 vs 6.1.1) | A missing filter on Windows | SP3 in CI before 3a.5. Encoder-version tags are never pinned. |
| HDR or unusual own video | Washed-out or broken clips | Normalised at import. MP4/MOV only, and the probe facts come from our own box walker, so they are identical on both platforms (B2). SP1 tries a real iPhone HLG clip. The codec and limit allowlist; `MEDIA_UNSUPPORTED` with a reason. |
| The render temp volume | Pass-1 intermediates take ~350 MB per 15 s render, up to ~1.4 GB with four in parallel (critic's probe at `-qp 0`) | Near-lossless CRF 8 on the local `userData` volume (backlog 2). SP1 measures the real size. The folder is swept on start. |
| A crafted file (audio, sticker, own media) exploits ffmpeg or a decoder | Code execution in a child process | The host allowlist, size caps and header checks. ffmpeg runs in its own process with an allowlisted env, never in main. Own files come only through main's dialog. |
| No fades: an abrupt audio cut at the end | A click at the loop point | The owner said no fades. If he hears a click, the fix is a ≤ 10 ms anti-click ramp; that is his call, not a default. |
| CI time (`bun test ./studio` is capped at 10 min) | A red CI on the 4-vCPU Windows runner | Low-res clips ≤ 2 s in unit tests. PNG-level text references. Five pairwise packaged renders (S14). |
| Disk growth | ~50 MB per manual refresh; ~3 MB per video (×2 with the export copy); own-video mezzanines | Manual refresh only. Export copies are disposable. Pruning goes to Stage 4. |
| flashapi changes shape or disappears; the list skews UA/CIS | An empty or irrelevant list | A lenient schema and a cached list that works offline. `MUSIC_UNAVAILABLE`. The Apple RSS + IG search alternative stays noted, as the owner decided. |
| Licensing | Pre-existing: a GPL/**nonfree** `ffmpeg-static` («not legally redistributable», `-L` on macOS; S13), H.264/AAC patents. New: OFL fonts and emoji; `resvg` MPL-2.0 | Ship the OFL texts. Fold everything into Stage 2's "third-party notices" backlog item before a public release. Instagram tracks are for personal, non-commercial use. |
| The design isn't ready or doesn't match the spec | UI rework | 3d.0's control→spec table comes before UI. Gaps become contract tasks. |
